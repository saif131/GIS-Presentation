# Professional Dark Theme Presentation

A sleek, modern presentation interface with a dark theme for displaying your screenshots with immersive UI and enhanced image viewing.

## Features

- **Premium Dark Mode Design**
  - Elegant dark theme with subtle lighting effects
  - Immersive fullscreen experience optimized for presentations
  - Extra-large image display for maximum visibility
  - Professional transitions and animations
  - Minimalist controls that auto-hide during inactivity

- **Multiple Navigation Options**
  - Bottom control bar with arrow buttons
  - Side edge navigation for larger screens 
  - Keyboard navigation (arrow keys, space, or enter)
  - Touch swipe support for mobile devices
  - Visual progress bar indicating presentation progress
  - Slide counter showing current position

- **Advanced Functionality**
  - One-click fullscreen mode (button or 'F' key)
  - Double-click on image to toggle fullscreen
  - Presentation mode ('P' key) for distraction-free viewing
  - Auto-hiding controls during periods of inactivity
  - Visual loading indicator with progress during image preloading
  - Help tooltip with keyboard shortcuts
  - Fully responsive design for all device sizes

## How to Use

1. Simply open the `index.html` file in any modern web browser
2. Navigate between slides using:
   - The central control bar at the bottom
   - Side edge navigation areas (hover near left/right edges)
   - Arrow keys on your keyboard
   - Space or Enter key to advance
   - Swipe left/right on touch devices
3. Double-click any image or use the fullscreen button for immersive viewing
4. Hover over the question mark icon to view keyboard shortcuts
5. Press 'P' to enter presentation mode with minimized interface elements

## Customization

If you want to customize the presentation:

1. Add your images to the "New folder" directory
2. Edit the `slides` array in the `script.js` file to include new images and descriptions
3. Customize the dark theme colors and styling in `styles.css`
4. Adjust the presentation title in the HTML file

## Technical Requirements

- Any modern web browser (Chrome, Firefox, Safari, Edge)
- No internet connection required (works completely offline)
- Font Awesome is loaded from CDN but will gracefully degrade if offline
